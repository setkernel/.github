# Contributing

Thanks for your interest. Issues and pull requests are welcome on our open-source repositories.

1. **Open an issue first** for anything bigger than a small fix, so we can agree on the approach.
2. **Keep pull requests small and focused.** Describe what changed and how you tested it.
3. **Follow the repository's own README and `AGENTS.md`** for commands and conventions. CI must pass.
4. Every pull request is reviewed and approved by a SetKernel maintainer before it's merged.

Workflow runs from first-time contributors need a maintainer's approval before they start. Please be patient.
By contributing you agree that your contribution is licensed under the repository's license.
