# Code of conduct

We want our projects to be welcoming and professional for everyone. Be respectful and constructive,
assume good intent, and focus on the work. Harassment, discrimination and personal attacks are not
tolerated, whether in issues, pull requests or any other project space.

Maintainers may remove, edit or reject contributions that break this code, and may block people who
repeatedly break it. Report concerns to [hello@setkernel.com](mailto:hello@setkernel.com). Reports are
handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
